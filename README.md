# Japanese Paper Toy – Texture Design

Texture design for a papercraft character toy (flat-pack folding model).

## Project
- Client: independent papercraft toy designer
- Scope: full texture design across 7 surfaces (body front/back/side, head, ears, tail)
- Style: Japanese traditional motifs — seigaiha waves, koi, bamboo, chochin lantern, kitsune mask

## Palette
| Color | Hex | Role |
|---|---|---|
| Vermilion | #D9333F | accent, primary motif |
| Paper white | #F4EDE1 | base |
| Ink black | #1A1614 | linework |
| Gold | #B8892F | trim, crease lines |
